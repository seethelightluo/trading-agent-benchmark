## 1. 全局生成参数

| 参数 | 值 | 说明 |
|---|---|---|
| BASELINE_DATE | 2026-07-16 | warmup↔在线分界（真实收盘锚定） |
| agent_visible_cutoff | 2026-07-15 | Agent 研究可见截止日 |
| ONLINE_END | 2035-12-31 | 兜底上限；逐 WL 取 max(阶段 end_date) |
| LEAD_TIME_FRAC | 0.35 | news 在段内 35% 时点破裂 |
| LEAD_MOVE_FRAC | 0.25 | news 前价格先走 25% leak |
| LINEAR_FLOOR | VIX≥9.0 / US10Y≥0.05 / CN10Y≥0.05 | 线性资产防负 |
| LINEAR_ASSETS | US10Y, CN10Y, VIX | 水平线性插值+平移锚定 |
| FX_DERIVE | USDCNY, USDJPY, EURUSD | 无轨迹汇率由 DXY 按 β 派生 |
| re-anchor | ON（默认） | 消除 warmup↔世界线边界断层 |
| derive-fx | ON（默认） | 缺失汇率由 DXY 派生 |
| price-leads-news | ON（默认） | leak 航点，news 滞后价格 |
| GBB noise | ON（默认） | 端点归零命中锚点 |
| 种子 | crc32(f"{wl}|{aid}") 每资产；crc32(f"{seed}|{k}") 每段 | 完全确定性 |
| 随机源 | numpy.random.default_rng | 无全局状态 |
