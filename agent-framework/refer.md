二、 核心框架的原生交易频段（Native Frequencies）

1. AlphaCrafter 原生频段：日频（Daily-Frequency）

2. FactorMiner 原生频段：日频（Daily Evaluation）
原生表现：FactorMiner 挖掘的是日频公式化阿尔法（Daily Formulaic Alphas）。它通过在日线上计算各种滚动统计量（如近 20 日收盘价标准差）来评估因子的信息系数（RankIC）和超额表现。

评估影响：它本身并不是一个多资产组合交易系统，而是一个因子发现与评估引擎。它只负责生成在日线上有预测能力的数学表达式（如 close / mean(close, 20)）并检验其有效性。它原生没有资产配置和持仓变动逻辑。

from core.miner.registry import EvaluatorRegistry

@EvaluatorRegistry.register_fitness_hook("turnover_aware")
def turnover_aware(factor_values, returns, base_metrics: dict) -> dict:
    ic = float(base_metrics.get("IC", 0.0))
    ic_ir = float(base_metrics.get("ICIR", 0.0))
    
    # 提取该因子在 19 类资产上的日频平均换手率 (0.0 到 1.0)
    turnover = float(base_metrics.get("Turnover", 0.0))
    
    # 设定工业级摩擦惩罚系数 (例如配置为单边综合费率的 2 倍，以强力压制高频噪声)
    penalty_coefficient = 0.05 
    penalty = penalty_coefficient * turnover
    
    # 最终适应度得分：高换手会直接让高 IC 因子失效
    fitness_score = (abs(ic) * 100 + ic_ir * 10) - penalty
    
    return {
        "fitness_score": fitness_score,
        "turnover_penalty": penalty,
    }

def turnover_aware(factor_values, returns, base_metrics: dict) -> dict:
    ic = float(base_metrics.get("IC", 0.0))

    }
